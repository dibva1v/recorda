
# Recorda

Recorda is a University Student Records Management System designed to simplify the management of student information and academic records.

## UH ID: 202401313

## Features
- Student record management
- Student information tracking
- RESTful API architecture
- Responsive user interface

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- Node.js and Express.js
- SQLite

## Installation

```bash
git clone https://github.com/dibva1v/recorda.git
cd recorda
npm install
npm run dev
```
